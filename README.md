# x86_64_tv-ota

Сервер обновлений для прошивок LineageOS 23.2 (Android 16) для x86_64 TV
(устройство `x86_64_tablet`, продукт `lineage_x86_64_tv`).

## Как получать обновления

Если в вашей прошивке есть приложение «Обновление системы» (System updates),
откройте его и включите проверку обновлений: оно найдёт здесь свежую сборку,
скачает её и предложит перезагрузиться для установки. Установка идёт штатным
механизмом (update engine), ничего вручную прошивать не надо.

Сборка публикуется не каждый день: если список пуст или совпадает с текущей
версией — вы уже на свежей. Приложение проверяет само раз в неделю.

## Старая прошивка без настроенного сервера (один раз)

В сборках до осени 2026 приложение проверяло обновления на сервере
LineageOS, где для наших сборок ничего нет, поэтому список был всегда пуст.
Достаточно один раз в терминале (adb shell или локальный терминал, root):

```
su 0 setprop lineage.updater.uri https://raw.githubusercontent.com/LOS-TV-FORK/x86_64_tv-ota/main/x86_64_tablet/builds.json
```

После этого появятся проверки на наш сервер. Когда через это обновление
установится сборка со встроенным адресом сервера, действие больше
не потребуется.

## Проблемы

- «Ошибка сети» в приложении обновлений — проверьте доступ в интернет
  (Wi-Fi/Ethernet) и настройки прокси.
- Обновление скачалось, но не ставится — сначала убедитесь, что на устройстве
  достаточно свободного места.
